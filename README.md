# WardHub NSO — หน้าเปิดแอปรายงานยอดประจำวัน

หน้าเปิด (launcher) สำหรับติดตั้งระบบรายงานยอดประจำวันเป็นแอปบนหน้าจอมือถือ ใช้ GitHub Pages
- เปิดจากเบราว์เซอร์: มีปุ่ม "เข้าสู่ระบบ" และวิธีติดตั้งเป็นแอป
- เปิดจากไอคอนที่ติดตั้งไว้: ไปที่ระบบ (Google Apps Script) ทันที
- ไม่มีข้อมูลผู้ป่วยหรือรหัสผ่านใน repo นี้ มีเฉพาะไอคอน ชื่อแอป และลิงก์ระบบ

เปลี่ยนลิงก์ระบบที่ตัวแปร `APP_URL` ใน `index.html`
